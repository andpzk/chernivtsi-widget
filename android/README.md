# Чернівці Світло для Android

Android 8.0 або новіший.

1. Встановіть APK на телефоні та затисніть порожнє місце на головному екрані.
2. У меню «Віджети» знайдіть «Чернівці Світло». Додайте «Чернівці · Кільце» або «Чернівці · Графік» і виберіть групу від 1 до 12.
3. Кожен віджет має свою групу. Торкніться встановленого віджета, щоб змінити її або перевірити графік зараз.

Кільце охоплює сьогоднішню добу. Широкий віджет додає другу смугу, коли опубліковано графік на завтра. Риска позначає київський час. Зелений означає планове живлення, червоний — планове відключення, жовтий — можливе заживлення, сірий — відсутність даних. Піктограма оновлення з часом показує, коли віджет перевірив графік. Віджети підлаштовуються під світлу й темну тему та системний формат годинника.

Джерело — [Чернівціобленерго](https://oblenergo.cv.ua/shutdowns/). Якщо сьогоднішній графік на офіційному сайті тимчасово недоступний, застосунок може використати свіжі [резервні дані](https://github.com/chaichuk/UA-power-outages-monitor) або збережений розклад. Графік показує планові періоди. Android може відкладати фонове оновлення через енергозбереження.

Починаючи з версії 1.4, під час фонового або ручного оновлення застосунок читає [налаштування дизайну з GitHub](https://github.com/andpzk/chernivtsi-widget/blob/android-design-v1/android/design.properties). Публічна копія GitHub може кілька хвилин показувати попередню ревізію. Після кожної правки збільшуйте `revision`, також коли повертаєте старі значення. Поля `ringSpacing` (від −1 до 2) і `wideSpacing` (від −1 до 3) змінюють відступи, поля `*TimeSize` — розмір часу. Після помилки мережі або некоректної правки залишається останній збережений дизайн. Група прив’язана до конкретного віджета на телефоні. Локальний `design.properties` містить початкові значення для тесту.

Для збирання відкрийте цю папку в Android Studio або запустіть `gradlew.bat :app:assembleDebug :app:lintDebug` з JDK 17 і Android SDK 35. На Windows використайте шлях із латинськими символами. Команда збірки створює тестовий APK у `app/build/outputs/apk/debug/app-debug.apk`.
